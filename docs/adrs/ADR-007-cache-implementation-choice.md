# ADR-007: Chuyển đổi cơ chế lưu trữ từ container memory sang Redis

## Trạng thái
PENDING

## Bối cảnh
Loại bỏ việc lưu trữ trạng thái và dữ liệu tạm thời ở bộ nhớ cục bộ của các container backend. Chuyển đổi toàn bộ sang lưu trữ tại một hệ thống cache trung tâm là Redis, được triển khai như một service độc lập bên trong mạng Docker Compose của dự án
